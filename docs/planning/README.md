# Planning Documents

This directory contains feature plans and implementation rationale. It is not
the source of truth for current product behavior; use
[`../PRODUCT.md`](../PRODUCT.md), [`../ARCHITECTURE.md`](../ARCHITECTURE.md),
[`../SECURITY.md`](../SECURITY.md), and [`../ROADMAP.md`](../ROADMAP.md) for
that.

- [`verificacion-hablante.md`](verificacion-hablante.md): implemented plan with

New plans should state their status, scope, alternatives, risks, migration
impact, tests, and manual acceptance criteria. When a plan becomes current
product behavior, update the canonical documentation and mark the plan as
implemented instead of silently leaving future-tense text behind.
